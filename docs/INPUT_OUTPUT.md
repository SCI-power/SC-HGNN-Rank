# Input and output contracts

## Model inputs

`data/model/Table_HGNN3_axis_label_table.csv` contains 600 rows in the exact
training order. `frozen_axis_id` is the primary key. Do not sort this table
without rebuilding all node/axis indices and split manifests.

Main identifier columns: `cancer`, `compound_master_id`,
`compound_representative_name`, `target_gene_symbol`, `tf_gene_symbol`,
`dominant_spatial_celltype`. Original source labels such as `T_NK_ILC` and
`Fibroblast_CAF` remain identifiers; manuscript display names T/NK and Fibroblast
do not change the indexed training inputs.

The ten base evidence features and ten interactions are listed by `validate`
and in `docs/data_dictionary.csv`. Continuous input values are numeric,
missing values follow the archived zero-fill rule and model features are clipped
to [0,1]. This numeric encoding is not a statement that unavailable assays were
experimentally negative.

`hgnn_label_ordinal` is 0, 1 or 2, assigned from cancer-specific evidence ranking.
`soft_rank_label` is the continuous integrated evidence label. These are
evidence-derived supervision, not newly measured biological ground truth.
The relation-disruption table nominates lower-evidence observed competitors;
its 873 rows are not 873 additional graph nodes or confirmed negative assays.

## Graph and tensor construction

`data/project/tables/` contains the seven harmonized evidence inputs used by
`build_spatial_causal_hgnn_graph_inputs.py`. The builder exports human-readable
nodes, edges, labels and relation constraints to `outputs/preprocess/graph/`.
The tensor builder then assigns categorical/index maps and produces tensors.
`prepare` compares the regenerated tensor and mappings to the archived model
input, including values and row order.

Node key: `node_id`. Edge endpoint keys: `source_node_id`, `target_node_id`.
Edge identity/type: `edge_id`, `edge_type`. Edge scores: `weight`,
`evidence_score`. Node `feature_score` becomes a scalar numeric feature.
The `.pt` file contains node types/scores, edge indices/types/weights, axis
indices, labels, soft scores, category maps and split metadata.

## Split and training contracts

The revision used `build_split_configs(labels, seed=20260807)`, not the older
random stratified split also stored in the tensor. The package loads those exact
saved assignments instead of regenerating library-dependent tie ordering. All 13 strict splits are
provided in `data/reference_runs/08_inductive/tables/Table_RI10_inductive_split_manifest.csv`.
Entity-edge masking is selected explicitly through `--protocol inductive`.
Training defaults: hidden width 112, 2 layers, dropout 0.18, AdamW learning rate
0.0016, weight decay 0.00015, 160 epochs, patience 28, gradient clipping 2.0.
The parameter-matched MLP width is selected from parameter count only (196 for
the supplied graph). Loss coefficients are preserved in the actual code and
the run configuration; no new objective is substituted during packaging.

## Output tables

- `run_metrics.csv`: one model x seed x held-out fold per row.
- `oof_predictions.csv.gz`: held-out-axis predictions with fold and seed keys.
- `axis_scores.csv`: mean/SD OOF scores and within-cancer rank/percentile.
- `model_summary.csv`: per-model, per-protocol-family mean/SD.
- `fold_level_paired_tests.csv`: five seeds averaged within each fold; 13 folds
  used for matched comparisons and 5,000 bootstrap resamples.
- `external_*`: direct-compound, target/regulator-class and protein endpoints
  evaluated separately on 272 distinct cancer-compound-target units.

Original archived seed-fold paired tests are retained as source records. The
headline manuscript comparison is the 13-fold analysis generated by `summary`.

## New inputs and external scores

To use different evidence inputs, create a separate compatible data tree and set
`SC_HGNN_DATA_DIR`; never edit the archived input in place. Rebuild the graph and
tensor and use a separately labelled analysis. The validation assertions for
600/960/9576/873 identify this manuscript dataset and must not be mistaken for a
universal biological constraint.

External evidence is joined by `frozen_axis_id` for axis-level review and by
cancer-compound-target keys for deduplicated endpoints. Preserve source release,
availability and matching category. A target-class drug record is not an exact
compound match. New OOF predictions must be explicitly joined by axis and fold;
the external script defaults to the frozen supplied predictions.
